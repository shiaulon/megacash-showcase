# Roteiro de demonstracao

Duracao recomendada: 60 a 90 segundos.

1. Abrir o app e mostrar a autenticacao sem expor credenciais.
2. Exibir o dashboard com dados ficticios e o resumo financeiro.
3. Registrar uma transacao e mostrar a atualizacao dos totais.
4. Abrir um cartao e explicar fechamento e vencimento da fatura.
5. Mostrar graficos, metas e planejamento.
6. Apresentar os planos Basic e Pro sem realizar uma compra real.
7. Abrir o mesmo usuario na Web para demonstrar sincronizacao.
8. Encerrar com o portal administrativo usando registros ficticios.

## Cuidados para gravacao

- Usar exclusivamente uma conta de demonstracao.
- Ocultar e-mails, nomes, saldos e documentos reais.
- Desativar notificacoes do sistema.
- Nao mostrar consoles, IDs de produto, tokens ou credenciais.
- Exportar em 1080p e adicionar legendas curtas.
